# Лабораторная работа: Очередь через два стека

Реализация структуры данных **Очередь (Queue)** с использованием двух **Стеков (Stack)** на языке C++.

## 📌 Описание проекта

Очередь работает по принципу **FIFO** (First In — First Out / "первым пришел — первым ушел"), а стек — по принципу **LIFO** (Last In — First Out / "последним пришел — первым ушел"). 


## 🛠️ Функционал (Реализованные методы)

**Обязательная часть:**
* `enqueue(int x)` — добавление элемента в конец очереди.
* `dequeue()` — удаление элемента из начала очереди.
* `front()` — просмотр первого элемента очереди без его удаления.

**Вариативная часть:**
* `contains(int x)` — проверка наличия элемента `x` в очереди без разрушения её структуры.


## 💡 Принцип работы алгоритма

Внутри класса используются два стека: `stack1` (входной) и `stack2` (выходной).

1. При вызове `enqueue()` элемент мгновенно падает на вершину `stack1`.
2. При вызове `dequeue()` или `front()` активируется внутренний механизм: если `stack2` пуст, все элементы из `stack1` последовательно переливаются в `stack2`. Из-за этого их порядок переворачивается, и самый "старый" элемент оказывается на вершине `stack2`, готовый к выдаче.
3. При вызове `contains()` создаются временные копии обоих стеков, что позволяет безопасно пробежаться по всем элементам и найти нужное число, не стирая данные из основной очереди.
